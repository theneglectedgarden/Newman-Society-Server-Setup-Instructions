# Newman Society Server Setup Instructions

## This page will explain how to set up your Minecraft instance in order to play on the UQ Newman Minecraft Server.
#### If you haven't already, install the Minecraft Launcher from: https://www.minecraft.net/en-us/download

### Java Download
#### Before you do anything, you must have Java downloaded. If you are unsure, download and run the following installer:

Windows: https://download.oracle.com/java/25/latest/jdk-25_windows-x64_bin.exe
<br>
MacOS: https://download.oracle.com/java/25/latest/jdk-25_macos-aarch64_bin.dmg 

### Step 1: Download and run the following:
https://maven.fabricmc.net/net/fabricmc/fabric-installer/1.1.2/fabric-installer-1.1.2.jar

### Step 2: Select 26.2 in the version selector:
Once you have opened the jar file, it will show the following screen:
<img width="922" height="604" alt="image" src="https://github.com/user-attachments/assets/e4719569-33ad-472c-b85d-5dc8e2b46223" />

Select 26.2, and press Install.
<img width="922" height="604" alt="image" src="https://github.com/user-attachments/assets/97406a6e-adc4-4411-9270-22673af91108" />

### Step 3: Open Minecraft

### Step 4: Click installations:
The launcher will look something like this. Click installations at the top.

It should automatically reveal itself. If it does not, please do not hesitate to ask for help:
